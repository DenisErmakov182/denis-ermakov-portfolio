# Портфолио: события и меню Telegram

Worker сохраняет только обезличенные события: источник, время, тип действия, название открытого кейса и путь страницы. Он не сохраняет IP-адрес, контакты, название вакансии или работодателя.

## Развёртывание

1. В Cloudflare создать D1-базу `portfolio-analytics`.
2. Скопировать `wrangler.toml.example` в `wrangler.toml` и подставить ID D1-базы. `wrangler.toml` не коммитить, если в нём появятся приватные данные.
3. Применить `schema.sql` к созданной D1-базе.
4. Добавить секреты Worker:
   - `TELEGRAM_BOT_TOKEN` — токен существующего PortfolioFeedbackBot;
   - `TELEGRAM_CHAT_ID` — ID личного чата владельца.
5. Развернуть Worker под существующим именем `portfolio-feedback`, чтобы сохранить работу формы обратной связи.
6. Установить webhook Telegram на путь `/telegram/webhook` этого Worker.
7. В Telegram открыть бота и отправить `/start`. Появятся кнопки «Сегодня» и «7 дней».

## Проверка после развёртывания

1. Открыть портфолио по ссылке с `utm_source=hh`.
2. Убедиться, что в Telegram пришло сообщение «Портфолио: новый посетитель» с источником `HH`.
3. Открыть кейс «ГПтест» и убедиться, что пришло отдельное сообщение о кейсе.
4. В боте нажать «Сегодня» и проверить, что в сводке появились оба события.
