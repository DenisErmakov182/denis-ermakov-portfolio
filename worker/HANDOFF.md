# Контрольная точка — 29.07.2026

## Цель

Добавить к портфолио минимальную обезличенную аналитику через уже существующий Cloudflare Worker `portfolio-feedback` и Telegram-бот `PortfolioFeedbackBot`.

События, которые учитываются:

1. Открытие портфолио.
2. Открытие кейса.
3. Скачивание резюме.
4. Клик по ссылке Telegram.

Для каждого события сохраняются только тип, источник, время, название кейса (только для открытия кейса) и путь страницы. Не сохраняются работодатель, вакансия, кампания, имя посетителя, контакты, IP-адрес или постоянный идентификатор.

Допустимые источники: `HH`, `HireHi`, `Хабр Карьера`, `Прямой контакт`, `Резюме (PDF)`, `Getmatch`, `Прямой / неизвестный`.

Пример уведомления в Telegram:

```text
Портфолио: открыт кейс «ГПтест»
Источник: HH
Дата и время: 29.07.2026, 14:32
```

Без поля «кампания» — это сознательное требование Дениса.

## Уже готово локально

- `analytics.js` — клиентская отправка событий с `utm_source`, сохранённым только в `sessionStorage` текущей сессии.

- Скрипт подключён к главной странице и четырём кейсам.
- `script.js` отправляет событие скачивания резюме; прежнее отдельное уведомление о резюме убрано, чтобы не было дубля.

- `worker/schema.sql` — таблица событий и индекс.

- `package.json` обновлён: сборка переносит новые статические файлы в `dist`.
